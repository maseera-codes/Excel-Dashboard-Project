# 📊 Vrinda Store Annual Report 2022

## 📌 Project Overview

This project is an Excel-based sales analysis dashboard created using the Vrinda Store dataset.

The goal of this project is to analyze sales and order data and present key business insights through PivotTables and PivotCharts.

## 🛠️ Tools & Techniques Used

- Microsoft Excel for the web
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard Analysis

The dashboard analyzes:

- Monthly Orders vs Sales
- Sales comparison between Men and Women
- Order Status distribution
- Top 5 States by Sales
- Orders by Age Group and Gender
- Orders by Sales Channel

## 🔍 Key Insights

- Women contributed a higher share of orders than men.
- Maharashtra was the highest-performing state among the top 5 states shown.
- Amazon was the largest order channel.
- The majority of orders were delivered successfully.
- Adult women represented the largest segment in the Age Group vs Gender analysis.
